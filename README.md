# NOVATERRA MACHINARY — GitHub Pages Website

Premium single-page static website for NOVATERRA MACHINARY, an India-based construction equipment merchant exporter.

## Publish on GitHub Pages
1. Create a new GitHub repository, e.g. `novaterra-machinary`.
2. Upload every file in this folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select your main branch and `/root`, then Save.
5. GitHub Pages will publish the static HTML/CSS/JS site. GitHub's official documentation confirms that Pages can host static files directly from a repository.
